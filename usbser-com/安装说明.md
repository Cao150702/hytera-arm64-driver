# 海能达 HP780 写频线 ARM64 Windows 驱动包

让写频线(USB\VID_238B&PID_0A11)在 **ARM64 Windows**(Windows 11 on ARM)上用微软内置
**WinUSB** 驱动,用户态程序可直连设备——绕开没有 ARM64 版的 MCCI 内核驱动。

## 前置条件(缺一不可)

1. **Secure Boot 必须关闭**(虚拟机:Parallels 配置 → 硬件 → 启动顺序 → 取消「安全启动」)
2. **测试签名模式开启**(管理员 PowerShell 执行 `bcdedit /set testsigning on` 后**重启**)
3. 重启后桌面右下角出现"测试模式"水印 = 生效

## 安装步骤

1. 用 `vm-scripts/make_cert.ps1` 生成本地测试证书,把根证书导入「**本地计算机** → **受信任的根证书颁发机构**」
2. 管理员 PowerShell:
   ```
   pnputil /add-driver <本目录>\Hytera-WinUSB.inf
   ```
   应显示「已成功添加驱动程序包」
3. 插上写频线。设备管理器 →「DMR Radio」设备应显示 **状态正常、Class=USBDevice、Service=WINUSB**(若还是感叹号:先 `pnputil /remove-device "USB\VID_238B&PID_0A11\实例ID"` 再重插,实例 ID 用 `pnputil /enum-devices /class USB` 查)

## 文件清单

| 文件 | 说明 |
|---|---|
| Hytera-WinUSB.inf | WinUSB 绑定 INF(含 CatalogFile 引用) |
| Hytera-WinUSB.cat | 目录文件——本仓库不附已签名版,请按 vm-scripts/ 生成并签名 |
| (测试证书) | 本仓库不附证书;用 vm-scripts/make_cert.ps1 生成本地测试证书后导入 |

## 说明

- 驱动层只解决"设备可用";写频软件需配合后续发布的**用户态写频工具**
  (WinUSB API 直连,协议详见《HP780写频协议规范.md》:HDLC 帧,读频 0xC7 分块命令)
- 签名证书为本地生成的测试证书,仅供个人测试使用
